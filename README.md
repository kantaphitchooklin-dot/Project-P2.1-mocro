# Smart Motor Cover QC & Sorting System

ระบบตรวจสอบคุณภาพและคัดแยกฝาครอบมอเตอร์อัตโนมัติบนสายพานลำเลียง ใช้ QR Code ระบุรุ่นของชิ้นงาน ตรวจสีด้วยเซนเซอร์สีและตรวจความสูงด้วยเซนเซอร์อัลตราโซนิก แล้วคัดแยกชิ้นงานลงถาดตามผลตรวจ พร้อมแสดงผลแบบเรียลไทม์บนเว็บแดชบอร์ด

โครงงานวิชาไมโครคอนโทรลเลอร์ ภาควิชาวิศวกรรมระบบไอโอทีและสารสนเทศ (IOTE) สถาบันเทคโนโลยีพระจอมเกล้าเจ้าคุณทหารลาดกระบัง (KMITL)

**Live dashboard:** https://th0wxnrat.github.io/smc-qc-dashboard/

---

## ภาพรวมระบบ

```
 QR Scanner ──► PC (qr_bridge.py) ──USART2──► STM32 NUCLEO-G071RB ──USART1──► ESP32 ──Wi-Fi──► Firebase ──► Web Dashboard
                                               │
                     IR sensor ◄───────────────┤
                     TCS34725 (สี) ◄──── I2C ──┤
                     HC-SR04 (ความสูง) ◄───────┤
                     Servo สายพาน ◄──── PWM ───┤
                     Servo คัดแยก ◄──── PWM ───┘
```

| ส่วน | หน้าที่ |
|---|---|
| **STM32 NUCLEO-G071RB** | ตัวควบคุมหลัก: อ่านเซนเซอร์ ตัดสินผล QC ควบคุมสายพานและแขนคัดแยก |
| **PC + `qr_bridge.py`** | รับข้อมูลจากเครื่องสแกน QR และคำสั่งจากคีย์บอร์ด ส่งต่อให้ STM32 ผ่าน USB (USART2) |
| **ESP32 DevKit V1** | รับผลตรวจจาก STM32 แล้วส่งขึ้น Firebase Realtime Database ผ่าน Wi-Fi |
| **Web Dashboard** | แสดงสถานะเครื่อง สถิติ PASS/REJECT กราฟ และดาวน์โหลด CSV ให้คนภายนอกดูได้ |

## การทำงานหนึ่งรอบ

1. ผู้ใช้สแกน QR Code ของรุ่นชิ้นงาน (หรือพิมพ์ `MODEL_A` / `MODEL_B` / `MODEL_C`)
2. สายพานเคลื่อนชิ้นงานเข้าอุโมงค์ตรวจ เมื่อเซนเซอร์ IR พบชิ้นงาน สายพานจะหยุด
3. อ่านค่าสี 5 ครั้งแล้วหาค่าเฉลี่ย และวัดระยะ 5 ครั้งแล้วใช้ค่ามัธยฐาน
4. ตัดสินสีที่ตรวจพบ แล้วเทียบกับสีที่รุ่นนั้นควรเป็น
   - ตรงกัน → **PASS**
   - ไม่ตรง หรืออ่านไม่ได้ → **REJECT**
5. แขนคัดแยกหมุนไปยังช่องของสีที่ตรวจพบ สายพานเดินต่อ ชิ้นงานตกลงถาด
6. ส่งผลขึ้นแดชบอร์ด แล้วแขนกลับตำแหน่งเริ่มต้น (ช่องแดง) เอง

| รุ่น | สีที่ต้องเป็น |
|---|---|
| `MODEL_A` | แดง |
| `MODEL_B` | น้ำเงิน |
| `MODEL_C` | เขียว |

## Hardware

### อุปกรณ์
- STM32 NUCLEO-G071RB
- ESP32 DevKit V1 (WROOM-32)
- TCS34725 RGB color sensor
- HC-SR04 ultrasonic sensor
- IR reflective sensor (IR LED + phototransistor)
- SG90 continuous rotation servo × 2 (สายพาน และแขนคัดแยก)
- เครื่องสแกน QR Code (USB)
- โครงสร้างพาสวูดสีขาว และสายพาน/เฟืองพิมพ์ 3D

### การต่อขา STM32

| อุปกรณ์ | ขา STM32 | ขาบนบอร์ด | หมายเหตุ |
|---|---|---|---|
| TCS34725 SCL | PB8 | D15 | I2C1, address 0x29 |
| TCS34725 SDA | PB9 | D14 | |
| HC-SR04 TRIG | PA0 | A0 | |
| HC-SR04 ECHO | PA1 | A1 | ผ่านวงจรแบ่งแรงดัน 10k / 20k (5 V → 3.3 V) |
| IR sensor | PA4 | A2 | Active LOW, pull-up 10k ไปที่ 3.3 V |
| LED แสดงผล IR | PA5 | D13 | |
| Servo คัดแยก | PA6 | D12 | TIM3_CH1, 50 Hz |
| Servo สายพาน | PA7 | D11 | TIM3_CH2, 50 Hz |
| UART ไป ESP32 | PA9 (TX) | D8 | USART1 → ESP32 GPIO16 (RX2), 115200 |
| UART ไป PC | PA2 / PA3 | USB | USART2, 115200 |

### ไฟเลี้ยง
- **5 V:** HC-SR04, IR LED, servo ทั้งสองตัว (ใส่ตัวเก็บประจุ 470 µF คร่อมไฟ servo)
- **3.3 V:** pull-up ของ phototransistor (ขา PA4 ไม่ทน 5 V)
- **GND ร่วมกันทุกบอร์ด**

## การติดตั้งและใช้งาน

### 1. STM32
1. เปิดโปรเจกต์ `SMC_STM32_Test` ด้วย STM32CubeIDE
2. กด **Build** แล้ว **Run**
3. **ห้ามกด Generate Code จากไฟล์ `.ioc`** เพราะโค้ดเขียนเองทั้งหมด การ generate จะเขียนทับ

### 2. ESP32
1. คัดลอก `secrets.example.h` เป็น `secrets.h` แล้วใส่ Wi-Fi SSID, รหัสผ่าน และบัญชี Firebase ของ ESP32
2. อัปโหลดด้วย Arduino IDE (บอร์ด ESP32 Dev Module)
3. **ห้าม commit `secrets.h` ขึ้น GitHub** (อยู่ใน `.gitignore` แล้ว)

### 3. PC
```
py -3.12 qr_bridge.py
```
คำสั่งทั้งหมดพิมพ์ในหน้าต่างนี้

### 4. ก่อนเปิดเครื่องทุกครั้ง
หมุนแขนคัดแยกด้วยมือให้อยู่ **ตำแหน่งช่องแดง** (พับชิดราว) เพราะ servo แบบหมุนต่อเนื่องจำมุมไม่ได้ บอร์ดจะเริ่มนับตำแหน่งจากจุดนี้

## คำสั่ง

### ใช้งานปกติ
| คำสั่ง | ความหมาย |
|---|---|
| `START` | เปิดสายพาน เริ่มโหมดอัตโนมัติ |
| `STOP` | หยุดสายพาน |
| `MODEL_A` / `MODEL_B` / `MODEL_C` | กำหนดรุ่นของชิ้นงานถัดไป (แทนการสแกน QR) |

### ทดสอบ (ใช้ตอน `STOP`)
| คำสั่ง | ความหมาย |
|---|---|
| `TEST:COLOR` | อ่านสีหนึ่งครั้ง และหมุนแขนไปช่องของสีนั้น |
| `TEST:HEIGHT` | วัดระยะด้วย HC-SR04 |
| `TEST:RECORD` | ส่งข้อมูลตัวอย่างขึ้นแดชบอร์ด |
| `TEST:C<us>` | ตั้งความเร็วสายพาน เช่น `TEST:C1800` |
| `TEST:STOP` | ตัดสัญญาณ servo ทั้งสองตัว |

### แขนคัดแยก
| คำสั่ง | ความหมาย |
|---|---|
| `TEST:GOR` / `TEST:GOG` / `TEST:GOB` | หมุนแขนไปช่องแดง / เขียว / น้ำเงิน |
| `TEST:HOME` | บอกบอร์ดว่าแขนอยู่ช่องแดงแล้ว (ใช้หลังหมุนด้วยมือ) |
| `TEST:PG<ms>` / `TEST:PB<ms>` | ตั้งตำแหน่งช่องเขียว / น้ำเงิน (เวลาที่หมุนจากช่องแดง) |
| `TEST:W<ms>` | เวลารอก่อนแขนกลับช่องแดง (ค่าเริ่มต้น 4000) |
| `TEST:F<ms>` / `TEST:R<ms>` | หมุนเดินหน้า / ถอยหลัง (ใช้หาค่าตำแหน่ง) |
| `TEST:DIV` | แสดงค่าปัจจุบันของแขน |

### ปรับเกณฑ์ตัดสินสี
| คำสั่ง | ความหมาย |
|---|---|
| `TEST:CAL` | แสดงเกณฑ์ปัจจุบัน |
| `TEST:RP<pct>` | R ต้องมากกว่า G และ B กี่ % จึงเป็นแดง (ค่าเริ่มต้น 140) |
| `TEST:GP<pct>` | G ต้องมากกว่า B กี่ % จึงเป็นเขียว (130) |
| `TEST:BP<pct>` | B ต้องไม่น้อยกว่า G กี่ % จึงเป็นน้ำเงิน (90) |

ค่าที่ตั้งด้วยคำสั่งจะหายเมื่อรีเซ็ตบอร์ด ถ้าต้องการให้ถาวร ให้แก้ค่าในส่วน `#define` ของ `main.c`

## รายละเอียดทางเทคนิค

### การตัดสินสี
ใช้ **สัดส่วน R : G : B** แทนค่าความสว่าง เพื่อให้ทนต่อแสงในห้องที่เปลี่ยนไป

| สี | เงื่อนไข |
|---|---|
| แดง | R > 1.4 × G และ R > 1.4 × B |
| เขียว | G > 1.3 × B และ G ≥ R |
| น้ำเงิน | B ≥ 0.9 × G และ B > R |
| อื่น ๆ | UNKNOWN |

ถ้าสีเป็น UNKNOWN แต่ HC-SR04 พบว่ามีชิ้นงานอยู่ ระบบจะใช้ความสูงช่วยตัดสิน และถ้าเซนเซอร์สีใช้งานไม่ได้ ระบบจะเข้าโหมดตัดสินด้วยความสูงอย่างเดียวโดยอัตโนมัติ

### แขนคัดแยกแบบ servo หมุนต่อเนื่อง
servo 360° ไม่สามารถสั่งให้ค้างที่มุมได้ (ความกว้างพัลส์ควบคุมความเร็วและทิศทาง) จึงควบคุมด้วย **เวลา**: หมุนตามเวลาที่กำหนดแล้วตัดสัญญาณให้หยุด ตำแหน่งนับเป็นมิลลิวินาทีจากช่องแดง

ทุกครั้งที่กลับช่องแดง แขนจะหมุนเลยเล็กน้อยให้ชนตัวกั้น ตำแหน่งจึงถูกรีเซ็ตทุกรอบ ไม่เกิดความคลาดเคลื่อนสะสม

### รูปแบบข้อมูลที่ส่งไป ESP32
```
RECORD: model=MODEL_A detected=RED expected=RED R=263 G=158 B=133 C=464 dist_cm=2.6 qc=PASS
STATUS: state=RUNNING model=MODEL_A
```
`state` เป็นได้: `STOPPED`, `WAIT_QR`, `RUNNING`, `DETECTED`, `MEASURING`, `SORTING`, `RELEASING`, `NO_QR`, `JAM`, `HALTED`

### Firebase
- `/records` ผลตรวจแต่ละชิ้น
- `/status` สถานะ ESP32 (heartbeat ทุก 30 วินาที)
- `/machine` สถานะเครื่องล่าสุด
- Rules: ทุกคนอ่านได้ เขียนได้เฉพาะบัญชีของ ESP32

## ปัญหาที่พบบ่อย

| อาการ | วิธีแก้ |
|---|---|
| `AUTO START refused` หรือเซนเซอร์สี error | เช็กสาย I2C (VIN, GND, SCL, SDA) แล้วตัดไฟทั้งระบบและเปิดใหม่ |
| แขนคัดแยกชี้ผิดช่อง | `STOP` → หมุนแขนกลับช่องแดงด้วยมือ → `TEST:HOME` → `START` |
| servo หมุนไม่หยุด | `TEST:D0` |
| `Auto mode is ON` | พิมพ์ `STOP` ก่อนใช้คำสั่ง `TEST:` |
| HC-SR04 อ่านค่าไม่นิ่ง | ชิ้นงานต้องหยุดตรงใต้เซนเซอร์ และห่างจากเซนเซอร์มากกว่า 3 cm |
| Build error เรื่อง duplicate definition | ย้ายไฟล์สำรอง เช่น `main - Copy.c` ออกจากโฟลเดอร์ `Core/Src` |

## ข้อจำกัดและแนวทางพัฒนาต่อ
- ค่าสีขึ้นกับแสงและตำแหน่งเซนเซอร์ ควรมีฝาครอบกันแสงและสอบเทียบใหม่เมื่อย้ายเครื่อง
- HC-SR04 ติดตั้งใกล้ชิ้นงานเกินไป ใกล้ระยะบอดของเซนเซอร์ ควรยกให้สูงขึ้น
- แขนคัดแยกควรใช้ servo แบบ 180° หรือเพิ่มเซนเซอร์บอกตำแหน่ง เพื่อความแม่นยำในระยะยาว
- เพิ่มการบันทึกค่าการตั้งค่าลงหน่วยความจำ Flash เพื่อไม่ต้องตั้งค่าใหม่หลังรีเซ็ต
